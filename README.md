# OCR-RADAR

Современное десктопное приложение для распознавания текста (OCR), разработанное на C++ с использованием фреймворка Qt. Программа позволяет извлекать текст с изображений, скриншотов и PDF-файлов, переводить его с помощью ИИ и вести историю своих действий.

#Возможности приложения включают:

- Распознавание текста (OCR): Поддерживает работу с изображениями, скриншотами и PDF-документами (до 10 страниц).
- Мультиязычность: Поддерживается 7 языков: русский, английский, японский, китайский, французский, немецкий, а также режим "все языки".
- ИИ-перевод: Встроенная функция перевода распознанного текста с помощью ИИ-модели. Язык перевода выбирается в окне профиля или вручную в верхней части главного окна.
- История: Хранит последние 30 распознаваний. В истории сохраняется исходное изображение, распознанный текст, перевод (если был выполнен), а также возможность перевести сохраненный текст на другой язык.
- Пробная версия: Работает без регистрации, но с ограничением на 15 распознаваний текста.
- Полная версия: Требует регистрации. Открывает доступ к профилю пользователя, полному функционалу и истории распознаваний.

#Технологии и зависимости

Проект написан на C++ с использованием Qt 6.10.2 (MSVC 2022, x86_64).

- Фреймворк: Qt (Widgets, возможно Multimedia и Network для ИИ).
- OCR Движок: Tesseract.
- Система сборки: CMake.

###  Важное требование для запуска:
Для корректной работы OCR необходимо установить **Tesseract** и убедиться, что он находится по следующему пути:
`C:\Program Files\Tesseract-OCR`

# Установка и сборка

Вариант 1: Через Qt Creator (Рекомендуется)
1. Установите Qt 6.10.2 (комплект MSVC 2022 64-bit) и CMake через Qt Maintenance Tool.
2. Установите Tesseract по пути `C:\Program Files\Tesseract-OCR` (если путь другой, измените его в коде).
3. Откройте `CMakeLists.txt` в Qt Creator.
4. Выберите Desktop Qt 6.10.2 MSVC2022 64bit в качестве комплекта (Kit).
5. Нажмите зеленую кнопку **Run** для сборки и запуска.

Вариант 2: Через командную строку (Visual Studio Developer Prompt)
```bash
git clone https://github.com/ВАШ_ЛОГИН/OCR-RADAR.git
